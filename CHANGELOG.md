# Changelog

## 0.1.0 (2026-11-03)

First release.

- `LazybirdTextToSpeech` component: text or SSML in, MP3 `ByteStream` out, with voice, locale, speed and more voice settings, set at initialization or per call. Sync and async.
- `list_voices` to search your own voices and the Lazybird library.
- Clear `LazybirdError` messages for an invalid API key, missing credits and other failed requests.
